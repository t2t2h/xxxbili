# DomainSniffer 2.0 — © أفلاطون (Aflatoon / Plato)

dylib مستقل يراقب اتصالات اللعبة ويعرضها بقائمة عائمة بتصميم Cyber-Terminal.
**لا يحتاج Substrate ولا ElleKit ولا أي تفعيل إضافي**: محرك الـ hook مدمج داخل الملف
(إعادة ربط رموز Mach-O لدوال C + ObjC runtime لـ NSURLSession).

## ما يلتقطه
- DNS: `getaddrinfo` و `gethostbyname`
- HTTP / رفع / تحميل / WebSocket عبر `NSURLSession`
- اتصالات IP مباشرة: `connect` و `sendto` (UDP)
- يميّز المحجوب من NextDNS (رد 0.0.0.0 أو ::) والفاشل

## 🌐 DNS تلقائي → 8.8.8.8 (جديد)
- مفعّل افتراضياً، وزر `DNS 8.8.8.8` في القائمة يشغّله ويوقفه (يُحفظ في `settings.json`).
- `getaddrinfo` و `gethostbyname`: تُحلّ الأسماء مباشرة عبر 8.8.8.8 (محلّل مدمج + كاش حسب TTL). إذا تعذّر الوصول لـ 8.8.8.8 يرجع تلقائياً لـ DNS النظام ويتجاوزه 20 ثانية.
- `connect` و `sendto`: أي اتصال بمنفذ 53 (UDP/TCP) إلى أي سيرفر DNS يتحوّل إلى 8.8.8.8 (أو `2001:4860:4860::8888` لـ IPv6)، والسجل يعرض العنوان الأصلي.
- قواعد RULES اليدوية لها الأولوية على الوضع التلقائي.
- ملاحظة: مع هذا الوضع لن يعمل كشف الحجب عبر NextDNS (لأن الردود تأتي من Google)؛ أوقف الزر إذا أردت ذلك.

## ⚡ وضع ALL → 8.8.8.8 (لحظي)
- زر `ALL → 8.8.8.8` (مطفأ افتراضياً). عند التشغيل: كل نطاق يُحلّ إلى 8.8.8.8، وأي `connect`/`sendto` لأي IP عام يتحوّل إلى 8.8.8.8 (المنفذ نفسه). يسري فوراً على أي اتصال جديد بدون إعادة تشغيل اللعبة (الاتصالات المفتوحة مسبقاً لا تتأثر).
- مستثنى: العناوين المحلية (127.x و192.168.x و10.x و172.16-31.x) وسيرفرات nextdns.io حتى تبقى القائمة شغّالة.
- تحذير: 8.8.8.8 سيرفر DNS فقط، فالألعاب والإنترنت لن تتصل أثناء التشغيل. أطفئ الزر لإرجاع كل شيء.

## 💬 وضع CHAT → 8.8.8.8
- زر `CHAT → 8.8.8.8` (مطفأ افتراضياً). عند التشغيل يتحوّل تلقائياً كل نطاق دردشة/كتابة أونلاين (chat, typing, messaging, websocket, mqtt, xmpp, agora, sendbird, pubnub, pusher, discord, telegram, whatsapp وغيرها) إلى 8.8.8.8، ويتعلّم الأداة IPs هذه النطاقات فتتحوّل أيضاً عند الاتصال المباشر بالـ IP.
- لإضافة كلمات خاصة بلعبتك (من سجل الأداة) ضع في `settings.json`: `"chatKeywords": ["كلمة1","كلمة2"]`.
- يسري لحظياً على الاتصالات الجديدة، ولا يمس باقي الاتصالات.

## 🔊 صوت عند دخول الروم الصوتي (ملف محلي فقط)
- عند الانضمام الفعلي لروم Agora (مثل غرف "يلا لودو")، يشتغل ملف صوت **محلي من جهازك** بدل أي صوت ثاني.
- **لا يوجد هنا أي استماع أو تسجيل لصوت أي شخص آخر** — فقط حدث "انضممت للروم" يشغّل ملفك المحلي.
- ضع الملف باسم `join.mp3` أو `join.wav` أو `join.m4a` أو `join.caf` داخل `Documents/DomainSniffer` على جهازك (فعّل مشاركة الملفات/File Sharing بالتطبيق أو استخدم ESign/Files للوصول للمجلد).
- زر `JOIN SOUND` يشغّل/يوقف الميزة. زر `SPEED x1/x2/x3/x4` يغيّر سرعة تشغيل الملف (تسريع صوتي حقيقي عبر `AVAudioPlayer.rate`، وليس تسريع فيديو أو تخطّي).
- أسماء دوال Agora تم تأكيدها من ثنائيات AgoraRtcKit.framework الحقيقية داخل IPA اللعبة (يلا لودو تستخدم أسلوب القنوات المتعددة AgoraRtcChannel/createRtcChannel:، فالـ hook على كائن القناة، مع احتياطي على AgoraRtcEngineKit للروم أحادي القناة).

## 🎙️ تسريع صوت المتكلمين داخل الروم (محافظ على النغمة)
- زر `VOICE SPEED` (مطفأ افتراضياً) + `MAX x1-x4`. يعالج صوت المتكلمين الحقيقي عبر API الرسمي لـ Agora لمعالجة الصوت الخام (`AgoraAudioDataFrameProtocol` / قبل الخلط لكل متكلم)، بمحرك WSOLA (تراكب-وإضافة) يحافظ على نغمة الصوت.
- **السرعة تتكيّف تلقائياً** حسب التراكم المتوفر فقط (الدردشة حيّة، ما فيه "مستقبل" ثابت نسرّع فيه): تتسارع بعد وقفات الكلام حتى الحد المختار، وتهدأ تلقائياً عند نفاد التراكم. هذا سلوك فيزيائي حتمي لأي صوت مباشر، موجود بأي تطبيق "لحاق ببث متأخر".
- اختُبر محرك المعالجة بمعزل عن اللعبة (محاكاة رياضية) قبل الدمج: النغمة تبقى شبه ثابتة، بدون تقطيع أو فجوات غير متوقعة.
- أي خلل غير متوقع بالبيانات الواردة من Agora يُمرَّر الصوت الأصلي بدون تعديل تلقائياً (fail-safe)، حتى لا تنقطع المكالمة أبداً.

## الميزات
- زر عائم متوهّج قابل للسحب يفتح القائمة.
- إحصائيات حيّة: TOTAL / DOMAINS / IPS / BLOCKED، بحث، وفلاتر.
- الضغط على أي سطر: حجب في NextDNS / استبدال / نسخ.
- 🔑 NEXTDNS KEY: مفتاح API يُكتب مرة وحدة ويُحفظ في `Documents/DomainSniffer/settings.json`.
- 🔁 RULES: قواعد استبدال (`1.1.1.1 ← 8.8.8.8`, `*.example.com ← 1.2.3.4`) بمفتاح تشغيل لكل قاعدة، وتُحفظ بعد الخروج من اللعبة.
- حفظ ومشاركة وتصدير Denylist.
